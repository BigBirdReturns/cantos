For developers

A working stdio MCP server, not a prompt template. Search the priceboard, calculate ownership, model qualified-route proposals and inspect permitted results with the same engine.

node compute/scripts/connect.cjs --mcp \
  --results /path/to/approved-results

Node 22+. Exact local paths are chosen once during setup. Your normal orchestration remains the execution authority. Optional read-only inputs: an Aperture aperture-support/1 hardware receipt (--aperture) and one explicitly configured model endpoint (--endpoint).
