Distance to the floor

Every GPU cloud with a ClusterMAX review page, rated against a written floor for a properly set up neocloud. Public evidence only. A shortfall is named with the sentence that shows it, and each shortfall has a likely fix. As of 2026-09-29.

How to read a row. Distance is the number of dimensions where public evidence shows the shop short of the floor. Unknown is the number of dimensions with no evidence either way; it never counts as short. Evidence is the number of distinct items behind the row, and rows under three are faded because a thin row is an artifact of a thin page, not a clean record. The ClusterMAX medal is shown as context and is never an input.

Three rules. No value is invented. Every row carries who produced it and under what conditions. Hot Aisle is the reference shop of this project and the project holds private measurements about it; none are used here, and its row is a third-party desk view with the disclosure attached.
