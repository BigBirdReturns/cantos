Run the workbench locally

Extract the ZIP, open a terminal in the extracted cantos folder and run this command with Python 3.10 or later. On Windows you can also double-click open-compute-ledger/start-workbench.cmd.

python -B open-compute-ledger/run.py --open

The launcher opens http://127.0.0.1:8841/. Select Accepted work, choose the Run 3 workload, set a service requirement and compare. Change an hourly rate under Cost assumptions and compare again. Open both editions under History to see how your price changed the decision. Your records stay on your computer.
