Cantos

Every GPU cloud rated against a written floor for what a properly set up neocloud delivers. The shortfall behind each miss is named in the provider's own review record, the fix is prescribed, and the evidence is refreshed from public sources every cycle. Where public data cannot answer, a seat is rented, the workload is run, and everything is retained so the number can be recomputed by anyone.

What the first cycle found

  • The floor is mostly configuration. The most common shortfalls across 85 providers are wired health checks (25), a working monitoring dashboard (23), Slurm or Kubernetes delivered working (16), and a usable shared filesystem (13). None is capital.
  • One clean zero. Nebius, on 28 evidence items. Thirty others sit at zero only because their record is a stub, and the table fades them.
  • The reference does not pass its own floor on public evidence. The shop whose measured performance anchors the floor rates distance 4 on its own ten-month-old public record. That is the first prescription, and it is the reference's.
  • The biggest waste is on the customer's side. Serving below the concurrency knee swings cost 23x. Two thirds of decode tokens in the qualified run went to requests that failed grading. The same accepted work prices five ways with no invoice.
  • The market disagrees with itself about price. Same-SKU on-demand prices spread 3x across providers, and the incumbent's TCO priors sit below 1 percent of observed listings.
